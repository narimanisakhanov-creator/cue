# cue

**Приватный ИИ-помощник поверх экрана для macOS и Windows.**

cue видит экран, распознаёт разговоры и помогает отвечать на вопросы, проводить встречи и решать задачи по программированию.

</div>

---

> [!IMPORTANT]
> cue предназначен для собственных заметок, обучения, доступности и тренировок. Использование скрытого помощника на прокторинге, собеседовании или записываемой встрече может нарушать правила платформы и требования к согласию на запись. Ответственность за использование программы лежит на пользователе.

## Возможности

cue работает как небольшая панель поверх других окон и использует три независимых источника данных:

| Возможность | Как запустить | Что используется |
|---|---|---|
| Помощь | `⌘` `↵` или `Ctrl` `Enter` | экран и недавний разговор |
| Что сказать? | кнопка в панели | звук встречи и микрофон |
| Уточняющие вопросы | кнопка в панели | весь разговор |
| Итоги | кнопка в панели | весь разговор |
| Задать вопрос | введите текст и нажмите `Enter` | экран и разговор |
| Решить задачу | `⌘` `H` или `Ctrl` `H` | экран |
| Умный режим | переключатель в поле ввода | более мощная модель |

Дополнительно в форке доступны русский интерфейс, русский язык ответов, копирование сообщений, трей, красный индикатор записи и Windows-сборка.

## Установка готовой версии

### macOS

1. Откройте раздел [Releases](../../releases) и скачайте архив `cue-mac.zip`.
2. Распакуйте архив и перенесите `cue.app` в папку «Программы».
3. При первом запуске нажмите по приложению правой кнопкой и выберите «Открыть».
4. Если macOS сообщает, что приложение повреждено, выполните:

```bash
xattr -cr /Applications/cue.app
```

### Windows

Windows-установщик доступен в [Releases](https://github.com/narimanisakhanov-creator/cue/releases). Для локального распознавания речи нужен Python 3.12 и однократная установка сервиса ниже. Установщик cue содержит папку `resources/app/speech` со скриптами сервиса; модели и Python-пакеты в `.exe` не включены.

## Запуск из исходников

Требуется Node.js 18 или новее.

```bash
git clone https://github.com/narimanisakhanov-creator/cue.git
cd cue
npm install
npm start
```

Сборка:

```bash
npm run pack       # локальная папка с приложением
npm run dist:win   # Windows-инсталлятор
```

macOS-сборка:

```bash
npm run dist
```

## Первичная настройка

1. Запустите cue и откройте настройки через кнопку `...`.
2. Выберите провайдера и добавьте свой API-ключ.
3. В поле «Endpoint API» можно указать любой совместимый endpoint (например, `https://api.example.com/v1`). Пустое поле использует адрес провайдера по умолчанию. Для OpenAI и Gemini в этой сборке по умолчанию используется `https://api.wikivibe.ru/v1`.
4. Для wikivibe выберите OpenAI-совместимый API и `gpt-6.1-sol` в обоих полях модели.
5. Windows: в «Конфиденциальность → Микрофон» разрешите доступ классическим приложениям; проверьте устройства в «Система → Звук». Отдельного разрешения «Запись экрана» в Windows нет. macOS: разрешите микрофон и запись экрана.

Ключи хранятся только локально в файле `cue-data.json`. В репозиторий ключи не добавляются.

### Распознавание речи

Распознавание независимо от провайдера ответов. По умолчанию используется локальный faster-whisper `small`, CPU/int8, русский язык. Для английского разговора выберите `en`, для смешанного — `auto` (короткие фразы могут определяться неверно).

Из корня исходников либо из установленной папки `resources/app` запустите в PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\speech\install-windows.ps1
```

Установка создаёт `%LOCALAPPDATA%\cue-speech\venv`, загружает модель в `%LOCALAPPDATA%\cue-speech\models` и регистрирует задачу входа `cue-speech`. После загрузки модели распознавание работает без интернета. Сервис слушает только `127.0.0.1:8765`; аудио при локальном режиме не уходит в wikivibe.

Настройки речи: **Локальный Whisper**, URL `http://127.0.0.1:8765/v1`, модель `small`, ключ пустой. Проверка: `curl.exe http://127.0.0.1:8765/health`. Ручной запуск: `powershell -NoProfile -ExecutionPolicy Bypass -File .\speech\start-windows.ps1`. Удаление автозапуска без удаления данных: `install-windows.ps1 -RemoveAutostart`.

Альтернатива — отдельный OpenAI-совместимый сервис с настоящим `/audio/transcriptions` и независимым ключом речи. Наличие chat API и модели `gpt-6.1-sol` не означает поддержку аудио.

## Управление

- `⌘` `↵` на macOS или `Ctrl` `Enter` на Windows - помощь по экрану и разговору.
- `⌘` `H` или `Ctrl` `H` - решить задачу программирования на экране.
- Кнопка с квадратом - начать или остановить запись.
Красный квадрат означает включённую сессию. Реальное состояние микрофона и звука компьютера показывают два индикатора в конспекте. После остановки последние фразы распознаются и итог сохраняется в `Документы\Cue`.
- Кнопка «Скрыть» сворачивает панель до верхней полосы.
- `⌘` `⇧` `T` или `Ctrl` `Shift` `T` - скрыть приложение в трей.
- Иконка cue в трее показывает окно, открывает настройки и завершает работу.
- Кнопка копирования переносит в буфер весь текущий диалог.
- `⌘` `⇧` `X` или `Ctrl` `Shift` `X` - выйти.

## Как это работает

cue построен на Electron. Основная логика выполняется локально, а запросы отправляются только выбранному пользователем ИИ-провайдеру.

- экран захватывается через Electron `desktopCapturer`;
- микрофон записывается через `getUserMedia`;
- звук встречи захватывается через `getDisplayMedia` с системным аудио;
- аудио преобразуется в PCM 16 kHz и отправляется на распознавание;
- ответ модели поступает в панель потоково.

Нет облачного сервера приложения, аккаунтов, телеметрии и аналитики. Дополнительный локальный сервис речи работает только на компьютере пользователя.

## Устранение проблем

**Не работает распознавание речи.**

Проверьте выбранный сервис речи, его URL и модель. Для локального режима `/health` должен показывать `model_ready: true`; лог — `%LOCALAPPDATA%\cue-speech\logs\server.log`. Для облачного режима нужен доступ к `/audio/transcriptions`, а не только chat API. Состояние источников должно быть «захват активен».

**Не появляется звук встречи.**

Windows: проверьте, что звук действительно играет через выбранные динамики, и индикатор «Звук компьютера» активен. Захватывается системный вывод, не отдельная вкладка. macOS: разрешите запись экрана; доступность loopback зависит от версии ОС/Electron.

**cue видно в демонстрации экрана.**

Скрытие от захвата является best-effort и не гарантируется всеми программами. Не используйте эту функцию для обхода правил платформ.

## Конфиденциальность

- нет аккаунтов, облачного сервера приложения и телеметрии;
- API-ключи хранятся только на компьютере пользователя в `cue-data.json`;
- при локальном распознавании аудио остаётся на компьютере; выбранный облачный STT получает аудио только во время записи;
- текст разговора и явно запрошенный снимок отправляются провайдеру ответов;
- расшифровка хранится в памяти, а итог и расшифровка сохраняются локально в Markdown при остановке/запросе итогов.
